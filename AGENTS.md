# Workspace instructions

The application is in `xauusd-ai-agent/`. Before working on it, read
[xauusd-ai-agent/AGENTS.md](xauusd-ai-agent/AGENTS.md) and follow its project instructions.

- Run application commands from `xauusd-ai-agent/`, where `.venv`, scripts and configuration live.
- Keep changes to the user's requested scope; preserve unrelated workspace files.
- Treat existing session authorization as continuing authorization. Do not introduce extra approval steps for routine, reversible work.
- Communicate with the user in Thai unless they request another language.

The design note at the workspace root is background material. Use the application source and current documentation to establish implemented behavior.

# ทดสอบวิธีเข้าด้วย indicator หลายแบบ — 6 พฤศจิกายน 2026

คำขอของผู้ใช้: ทดสอบวิธีเข้าด้วย indicator หลาย ๆ แบบ โดยแบ่ง Agent และ sub Agent ให้เหมาะสม

## วิธีทำ
- ใช้ Workflow แบ่งงานให้ agent 8 ตัว:
  - manager 1 ตัว ออกแบบวิธีเข้า 8 แบบจาก indicator คนละตระกูล
  - backtester 3 ตัว (กลุ่ม 3/3/2) เขียน `backtest/strategies/ent_*.py` และ `backtest/grids/ent_*.json`
  - verifier 3 ตัว ตรวจว่าไม่มี lookahead และตรงนโยบาย แล้วรันซ้ำ
  - manager จัดอันดับ
- ข้อมูล: `data/history/xm_gold_m1_36m.csv` (XM GOLD M1 2023-11-06 ถึง 2026-11-06)
- Walk-forward: เลื่อนช่วง (train 6 เดือน / test 1 เดือน, 30 รอบ) และแบบขยายช่วง (anchored) ใช้ objective `expectancy_r` และ `--live-risk-gate` จึงเทรดเฉพาะสัญญาณที่ Risk/Paper ปัจจุบันยอมรับ (RR สุทธิ ≥ 1.2, spread/ATR ≤ 0.20 ซึ่งเท่ากับ ATR M5 ≥ 3, stop 1–3 ATR)
- ทุกวิธีใช้ส่วนกลางเหมือนกัน:
  - เทรนด์ H1 จาก EMA50/EMA200
  - ATR M5 ≥ 3
  - เวลา server 02–22 และไม่เข้าวันศุกร์หลัง 20:00
  - stop จาก swing โดยจำกัดไว้ที่ 1.1–2.8 ATR
  - TP คำนวณจาก RR สุทธิหลังหักต้นทุน
  - grid 12 ค่าต่อวิธี: rr 1.5/2.0/2.5 × มี/ไม่มี breakeven × indicator 2 ค่า
- เกณฑ์ผ่าน:
  - แบบเลื่อนช่วง: E > 0, PF (USD) ≥ 1.2, อย่างน้อย 150 ไม้, DD ≤ 10%, รอบที่เป็นบวก ≥ 50%
  - แบบขยายช่วง: E > 0

## การตรวจสอบ
- verifier ทั้ง 3 ตัวตรวจโค้ดแล้ว:
  - indicator H1/H4 ป้อนจาก `ctx.new` ซึ่งมีเฉพาะแท่งที่ปิดแล้ว
  - สัญญาณใช้แท่ง M5 ที่ปิดแล้ว เข้าที่ราคาเปิดแท่งถัดไป
  - ไม่ส่งสัญญาณระหว่างที่มีไม้เปิด
  - ต้นทุนตรงกับ `config/risk-xm-paper.json`
- ผมรัน walk-forward แบบเลื่อนช่วงของ 2 ตัวแรกซ้ำเอง (`chk-ent_cci_wr_hook`, `chk-ent_heikin_ashi_flip`) ผล out-of-sample ตรงกับของ agent ทุกค่า
- `.venv/bin/python -m pytest -q` → 262 passed

## ข้อสังเกต
- **ไม่มีวิธีไหนผ่านเกณฑ์ครบ** แต่ 6 ใน 8 วิธีดีกว่า xm-0.2 ทั้ง E และ DD
- WR ขึ้นจาก 32% เป็น 37–40% ตามที่คาดจากการเข้าที่ปลาย pullback แทนตอนตัด EMA20 แต่ RR จริงลดลง จึงยังอยู่แถวเสมอตัว
- **เทรนด์ H1 ที่แรงช่วยทุกวิธี** (gap_atr 8 ดีกว่า 5, ER 0.30 ดีกว่า 0.20) ส่วน **breakeven ทำให้แย่ลงเกือบทุกกรณี**
- gate ATR ≥ 3 ทำให้ช่วงแรกของข้อมูลแทบไม่มีไม้ จึงข้ามไป 7–13 รอบจาก 30 รอบ ตัวอย่างส่วนใหญ่จึงมาจากปีหลัง
- ข้อควรระวังของ `ent_cci_wr_hook`:
  - `best_month_share` 1.11 คือเดือนที่ดีที่สุดเดือนเดียวกำไรมากกว่ากำไรสุทธิทั้งช่วง
  - edge อยู่ที่ cci_level 150, rr 2.5 เท่านั้น ส่วน config 0 ได้ประมาณ 0
- `ent_heikin_ashi_flip` มีค่าพารามิเตอร์ที่นิ่งกว่า (ER 0.30 ดีกว่าทุกคู่) แต่ `best_month_share` 1.78 และมีเพียง 1 ไม้ต่อสัปดาห์

## สรุป
1. ยังไม่ควรเอาวิธีไหนไปแทน xm-0.2 ใน Paper เพราะยังไม่ผ่านเกณฑ์ และ PF ประมาณ 1.05–1.07 ยังอยู่ในระดับที่ความคลาดเคลื่อนสุ่มอธิบายได้
2. ถ้าจะทดสอบต่อ:
   - ล็อกค่าไว้ล่วงหน้าโดยไม่แก้ grid อีก: `ent_cci_wr_hook` config 10 (cci_level 150, rr 2.5, ไม่มี BE) และ `ent_heikin_ashi_flip` config 0 (ER 0.30, rr 2.0)
   - รันแบบ shadow บนข้อมูลใหม่คู่กับ xm-0.2 จนได้ราว 100 ไม้ต่อวิธี
3. xm-0.2 ใน Paper ยังมี E ติดลบชัดเจน ทางเลือกคือพัก entries หรือเพิ่มตัวกรองเทรนด์ H1 ที่แรง (เช่น ระยะ EMA50–EMA200 ≥ 5–8 ATR M5) ซึ่งช่วยทุกวิธีในการทดสอบนี้ ทั้งสองทางเป็นการเปลี่ยนนโยบายที่ต้องให้ผู้ใช้ตัดสิน

# XM Control บน Mac

เปิด `mac/build/XM Control.app` ด้วย Finder ได้เลย แอปนี้รวมตัวควบคุมบริการ Python และหน้าจอภาษาไทยไว้ในหน้าต่างเดียว สามารถลากแอปไปไว้ใน Dock ได้โดยเก็บโฟลเดอร์โครงการไว้ที่เดิม

## หน้าจอ

- ภาพรวมระบบ: ราคา GOLD, ความสดของ MT5 / tick, การเชื่อม LM Studio และโมเดลที่โหลด, worker, ยอดบัญชี และเหตุการณ์
- บัญชีและสถานะ: Balance, Equity, กำไรขาดทุนที่ยังไม่ปิด, cash P/L ที่รวมค่าธรรมเนียมบันทึกแล้ว, สถานะเปิด และ 100 เทรดปิดล่าสุด
- การวิเคราะห์ AI: งานล่าสุด, คำตอบ AI, effective decision หลัง Risk/expiry และเหตุผลของโมเดล คำตอบ BUY/SELL ของ AI ไม่รับประกันว่าจะเปิดสถานะ
- บันทึกเหตุการณ์: เปิด–ปิดไม้จำลอง, ผล AI, การพัก/รับสัญญาณ และบริการขัดข้อง/กลับมาทำงาน เก็บล่าสุด 2,000 เหตุการณ์

รีเฟรชหน้าจอทุก 5 วินาที ตรวจ LM Studio และบริการทุก 15 วินาที แจ้งการเชื่อมต่อขัดข้องหลังตรวจเสียต่อเนื่อง 3 รอบ กราฟเก็บจุดทุก 30 วินาที แสดงล่าสุด 120 จุด (ประมาณ 60 นาทีเมื่อระบบทำงานต่อเนื่อง) จุดที่ใช้ราคาเก่าระบุไว้ ไม่ใช่เส้นทางราคาย้อนหลังระหว่างปิดบริการ

## ปุ่มควบคุม

แถบ **ผู้วิเคราะห์ AI** เลือก **LM Studio** หรือ **Codex · ChatGPT** และจดจำค่าข้ามการเริ่มใหม่ งานที่กำลังวิเคราะห์ใช้ตัวเดิมจนจบ ส่วนงานถัดไปใช้ตัวเลือกใหม่ Codex ใช้อินเทอร์เน็ตและโควตาบัญชี ChatGPT ดู [คู่มือ Codex](CODEX.md)

**เริ่มบริการ** เปิด receiver ที่ `127.0.0.1:8001` และ XM/AI/Paper ที่ `127.0.0.1:8002` หากรันอยู่แล้วจะใช้ตัวเดิม ไม่สร้าง worker เพิ่ม และไม่เปิด MT5/LM Studio แทนผู้ใช้

**พักเปิดไม้ใหม่** บันทึกสถานะพักลงฐานข้อมูลอย่างถาวร ห้ามเข้าใหม่แต่ติดตามราคาและ SL/TP เดิมต่อ สัญญาณที่รออยู่ยังหมดอายุตามกฎเดิม กด **เปิดรับไม้ใหม่** เพื่อกลับมารับ entry เมื่อผ่าน AI/Risk/กฎบัญชี

**หยุดบริการ** พักการเข้าใหม่ก่อน และหยุดได้เมื่อไม่มีสถานะเปิดเท่านั้น หากมีไม้เปิดจะคงบริการติดตามไว้ ปุ่มนี้ไม่หยุด MT5 หรือ LM Studio ไม่ล้างยอดเงิน/ประวัติ และจะคงสถานะพักไว้หลังเริ่มบริการครั้งต่อไป ตัวควบคุมตรวจ port, user, command และ working directory ก่อนหยุด ไม่ส่งสัญญาณไปยังโปรแกรมอื่น และไม่ใช้ force kill

ถ้ารัน `sh scripts/run_xm.sh` ใน Terminal อยู่ แอปใช้บริการนั้นได้ เมื่อกดหยุดบริการ Terminal นั้นจะออกจากการรันด้วย หากเริ่มผ่านแอป log จะอยู่ใน `.runtime/xm.log` และ `.runtime/receiver.log`

## การแจ้งเตือน Mac

กด **เปิดการแจ้งเตือน** ครั้งแรก แล้วอนุญาตใน macOS หากยังปิดอยู่ ให้ไป **System Settings → Notifications → XM Control → Allow Notifications** เมื่อหน้าจอแสดงว่าเปิดแล้ว กด **ทดสอบการแจ้งเตือน** เพื่อส่งข้อความทดสอบ

แจ้งผล AI ใหม่, เปิด–ปิดไม้จำลอง, เปลี่ยนสถานะพัก, ถึงเพดานรายวัน และการเชื่อมต่อขัดข้อง/ฟื้นตัว เริ่มครั้งแรกจะไม่ส่งประวัติเก่าทั้งหมดซ้ำ หลังจากนั้นจดจำ event ID เพื่อส่งแต่เหตุการณ์ที่ยังไม่ได้ประมวลผล แจ้งเตือนเป็นแบบ best effort ของ macOS; Focus, การตั้งค่าแสดงแบนเนอร์, การออกจากแอป หรือเครื่องหลับอาจทำให้ไม่เห็นทันที

ปิดหน้าต่างด้วยปุ่มแดง แอปยังอยู่ในแถบเมนู **◈ XM** และตรวจต่อ เปิดกลับได้จากเมนู **แสดง XM Control** การเลือก **ออกจาก XM Control** จะหยุดตรวจและแจ้งเตือนของตัวแอป แต่บริการ Python ยังทำงานอยู่ ขณะนี้ไม่ได้ติดตั้งให้เปิดพร้อมล็อกอิน Mac

รายงานการส่งแจ้งเตือนครั้งล่าสุดอยู่ที่ `.runtime/mac-notifications.json` มีเพียงสถานะ accepted/delivered และเวลา ไม่มี token หรือข้อความ AI

## Build อีกครั้ง

ต้องมี Xcode Command Line Tools, Python `.venv` ของโครงการ และ macOS 13 ขึ้นไป ปิดแอปก่อน build:

```sh
sh scripts/build_mac.sh
```

แอปสร้างจาก Swift/AppKit/WKWebView และไฟล์ `dashboard/` ในโครงการ ลงลายเซ็นแบบ ad hoc สำหรับใช้ในเครื่องนี้ ไม่มีการอัปโหลดเว็บหรือฐานข้อมูลขึ้นคลาวด์ หากย้ายโฟลเดอร์โครงการให้ build ใหม่เพื่อบันทึกตำแหน่งที่ถูกต้อง

UI อ่านข้อมูลผ่าน native bridge โดย Python API ใช้ bearer token ภายในแอปเท่านั้น ไม่มี token ใน JavaScript, URL, app bundle หรือข้อความแจ้งเตือน API `/dashboard/state` และ `/dashboard/pause` ต้องยืนยันตัวตน แอปรับเฉพาะหน้าที่ bundle ไว้และคำสั่งที่กำหนดตายตัว

## ขอบเขต

เป็นบัญชี Paper Trading ใน Python ไม่ใช่ยอดเงินจริงหรือยอดบัญชี Demo ของ XM ปุ่มไม่มีการส่งออร์เดอร์ไป MT5 การจำลองยังมีข้อจำกัดตาม [PAPER.md](PAPER.md) และคุณภาพเหตุผล AI ต้องประเมินเพิ่มเติม แม้โมเดลเชื่อมต่อและตอบตาม schema ได้แล้ว

# XM Control บน Mac

เปิด `mac/build/XM Control.app` ด้วย Finder ได้เลย แอปนี้รวมตัวควบคุมบริการ Python และหน้าจอภาษาไทยไว้ในหน้าต่างเดียว สามารถลากแอปไปไว้ใน Dock ได้โดยเก็บโฟลเดอร์โครงการไว้ที่เดิม

## หน้าจอ

| หน้า | เนื้อหา |
| --- | --- |
| ภาพรวมระบบ | ราคา GOLD และความสดของ MT5, สถานะ engine และการอุ่นเครื่อง, สภาพตลาดตามกลยุทธ์ (แนวโน้ม, RSI(2), ไม้ตามกลยุทธ์ที่ยังไม่จบ), สัญญาณล่าสุดพร้อม Entry/SL/TP และเวลาที่ยังเข้าได้, กติกากลยุทธ์ และเหตุการณ์ |
| ประวัติสัญญาณ | 50 สัญญาณล่าสุด พร้อมสถานะ `แจ้งแล้ว` / `เลยเวลาแจ้ง` / `ระหว่างอุ่นเครื่อง` / `ไม่ผ่าน Risk` และเหตุผล |
| บันทึกเหตุการณ์ | สัญญาณเข้า trade, การเริ่มคำนวณใหม่, การปิด/เปิดเสียง และบริการขัดข้อง/กลับมาทำงาน เก็บล่าสุด 2,000 เหตุการณ์ |

- หน้าจอรีเฟรชทุก 5 วินาที บริการตรวจ receiver และราคาทุก 15 วินาที แจ้งการเชื่อมต่อขัดข้องหลังตรวจเสียต่อเนื่อง 3 รอบ
- ไม่มีส่วนของ AI, บัญชี Paper หรือโหมดยกเว้นแล้ว ([เหตุผลและโหมดเดิม](ALERTS.md#โหมด-aipaper-เดิม))

## ปุ่มควบคุม

**เริ่มบริการ** เปิด receiver ที่ `127.0.0.1:8001` และบริการแจ้งเตือน (`app.alert_main`) ที่ `127.0.0.1:8002` หากรันอยู่แล้วจะใช้ตัวเดิม ไม่สร้าง worker เพิ่ม และไม่เปิด MT5 แทนผู้ใช้

**ปิดเสียงแจ้งเตือน** หยุดส่งการแจ้งเตือนสัญญาณ:

- ระบบยังคำนวณและบันทึกสัญญาณในประวัติต่อ
- ค่าจะถูกบันทึกในฐานข้อมูลและจดจำข้ามการเริ่มใหม่
- กด **เปิดเสียงแจ้งเตือน** เพื่อกลับมาแจ้ง
- การแจ้งเรื่องการเชื่อมต่อยังทำงานตามปกติ

**หยุดบริการ** หยุด receiver และบริการแจ้งเตือน ไม่หยุด MT5 ตัวควบคุมตรวจ port, user, command และ working directory ก่อนหยุด ไม่ส่งสัญญาณไปยังโปรแกรมอื่น และไม่ใช้ force kill

ถ้ารัน `sh scripts/run_xm.sh` ใน Terminal อยู่ แอปใช้บริการนั้นได้ เมื่อกดหยุดบริการ Terminal นั้นจะออกจากการรันด้วย หากเริ่มผ่านแอป log จะอยู่ใน `.runtime/xm.log` และ `.runtime/receiver.log` ถ้าพอร์ต 8002 เป็นบริการ Paper เดิม (`run_xm_paper.sh`) แอปจะไม่หยุดให้

## การแจ้งเตือน Mac

กด **เปิดการแจ้งเตือน** ครั้งแรก แล้วอนุญาตใน macOS หากยังปิดอยู่ ให้ไป **System Settings → Notifications → XM Control → Allow Notifications** เมื่อหน้าจอแสดงว่าเปิดแล้ว กด **ทดสอบการแจ้งเตือน** เพื่อส่งข้อความทดสอบ

การ์ด **Telegram** แสดงสถานะการส่งไป Telegram (ปิดอยู่, ยังไม่ได้ใส่ token/chat ID, พร้อมส่ง หรือส่งไม่สำเร็จ) ปุ่ม **ส่งข้อความทดสอบ** ซึ่งแสดงเมื่อตั้งค่าครบแล้ว และปุ่ม **เปิดรับคำสั่ง /status** หรือ **ปิดรับคำสั่ง /status** ซึ่งเป็นสวิตช์ให้ถามสถานะจากแชทได้ (ปิดเป็นค่าเริ่มต้น ระหว่างที่ปิด Mac ไม่ดึงข้อความจาก Telegram) เมื่อเปิด บรรทัดล่างของการ์ดจะต่อท้ายด้วย "รับคำสั่งอยู่" หรือ "รับคำสั่งไม่ได้" วิธีตั้งค่าอยู่ใน [ALERTS.md](ALERTS.md#ส่งแจ้งเตือนไป-telegram)

แจ้งสัญญาณเข้า trade (ฝั่ง, ราคาอ้างอิง, SL, TP, RR, เวลาที่ยังเข้าได้ และเวลาปิดตามกลยุทธ์), การเริ่มคำนวณใหม่, การปิด/เปิดเสียง และการเชื่อมต่อขัดข้อง/ฟื้นตัว เริ่มครั้งแรกจะไม่ส่งประวัติเก่าทั้งหมดซ้ำ หลังจากนั้นจดจำ event ID เพื่อส่งแต่เหตุการณ์ที่ยังไม่ได้ประมวลผล แจ้งเตือนเป็นแบบ best effort ของ macOS; Focus, การตั้งค่าแสดงแบนเนอร์, การออกจากแอป หรือเครื่องหลับอาจทำให้ไม่เห็นทันที

ปิดหน้าต่างด้วยปุ่มแดง แอปยังอยู่ในแถบเมนู **◈ XM** และตรวจต่อ เปิดกลับได้จากเมนู **แสดง XM Control** การเลือก **ออกจาก XM Control** จะหยุดตรวจและแจ้งเตือนของตัวแอป แต่บริการ Python ยังทำงานอยู่ ขณะนี้ไม่ได้ติดตั้งให้เปิดพร้อมล็อกอิน Mac

รายงานการส่งแจ้งเตือนครั้งล่าสุดอยู่ที่ `.runtime/mac-notifications.json` มีเพียงสถานะ accepted/delivered และเวลา ไม่มี token หรือเนื้อหาข้อความ

## Build อีกครั้ง

ต้องมี Xcode Command Line Tools, Python `.venv` ของโครงการ และ macOS 13 ขึ้นไป ปิดแอปก่อน build:

```sh
sh scripts/build_mac.sh
```

แอปสร้างจาก Swift/AppKit/WKWebView และไฟล์ `dashboard/` ในโครงการ ลงลายเซ็นแบบ ad hoc สำหรับใช้ในเครื่องนี้ ไม่มีการอัปโหลดเว็บหรือฐานข้อมูลขึ้นคลาวด์ หากย้ายโฟลเดอร์โครงการให้ build ใหม่เพื่อบันทึกตำแหน่งที่ถูกต้อง

UI อ่านข้อมูลผ่าน native bridge โดย Python API ใช้ bearer token ภายในแอปเท่านั้น ไม่มี token ใน JavaScript, URL, app bundle หรือข้อความแจ้งเตือน API `/dashboard/state` และ `/dashboard/pause` ต้องยืนยันตัวตน แอปรับเฉพาะหน้าที่ bundle ไว้และคำสั่งที่กำหนดตายตัว

## ขอบเขต

แอปแจ้งจังหวะเข้า trade ตามกลยุทธ์เท่านั้น ไม่ส่งออร์เดอร์ไป MT5 ไม่มีบัญชีจำลอง และไม่รู้ว่าผู้ใช้เข้าไม้จริงหรือไม่ ผลกลยุทธ์จาก backtest ไม่ใช่หลักฐานว่าจะทำกำไรได้ ดูข้อจำกัดใน [ALERTS.md](ALERTS.md#ข้อจำกัด)
